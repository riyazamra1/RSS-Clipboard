# RSS Clipboard

Lightweight native Android clipboard manager by Razeen Secure Solutions.

## Current foundation
- Kotlin + Jetpack Compose
- Room local storage
- Automatic clipboard capture while the app is active
- Automatic content detection: text, URL, email, phone, sensitive
- Search and category filters
- Copy, pin, edit and delete
- 24-hour default expiry for unpinned entries
- Automated GitHub Actions debug APK build

Package: `com.riyaz.rssclipboard`
